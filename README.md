2. Описание проекта

MLDesktopApp — десктопное приложение для классификации банкнот на подлинные и поддельные с использованием машинного обучения.

Приложение разработано на Python с использованием PySide6. Для классификации применяются две предварительно обученные модели библиотеки scikit-learn:

Логистическая регрессия (Logistic Regression).

Случайный лес (Random Forest).

Пользователь вводит четыре числовых признака банкноты, выбирает модель и запускает классификацию. Программа отображает результат, вероятности принадлежности к классам и время выполнения предсказания.

4. Используемые алгоритмы

4.1. Логистическая регрессия

Логистическая регрессия — алгоритм классификации, позволяющий оценивать вероятность принадлежности объекта к определённому классу.

В проекте используется Pipeline, включающий:

StandardScaler для стандартизации признаков.

LogisticRegression для классификации.

Параметры классификатора:

C = 10.

max_iter = 1000.

random_state = 42.

4.2. Случайный лес

Random Forest — ансамблевый алгоритм машинного обучения, объединяющий результаты нескольких деревьев решений.

Используемые параметры:

n_estimators = 100.

random_state = 42.

criterion = gini.

Для определения итогового класса используется голосование деревьев, а для оценки уверенности применяется predict_proba().

ML-ядро и сервисный слой не зависят от PySide6.

7. Фоновое выполнение и взаимодействие сигналов и слотов

Для выполнения классификации используется QThread.

Класс PredictWorker наследуется от QThread и выполняет следующие действия:

Получает входные данные и идентификатор модели.

Создаёт PredictionService.

Выполняет классификацию в отдельном потоке.

Передаёт результат в GUI через пользовательский сигнал.

При возникновении исключения отправляет сигнал с сообщением об ошибке.

Используются сигналы:

result_ready — передача результата классификации.

error_occurred — передача информации об ошибке.

Главное окно соединяет сигналы с соответствующими слотами, которые обновляют интерфейс.

Во время вычислений кнопка запуска блокируется, а пользователю отображается сообщение о выполнении операции. После завершения вычислений кнопка снова становится доступной.

Отзывчивость интерфейса проверена с помощью временной задержки в две секунды. Во время задержки окно продолжало реагировать на действия пользователя. После проверки задержка была удалена.

9. Установка и запуск

Для запуска необходим Python 3.12 или совместимая версия Python, поддерживающая используемые зависимости.

Клонирование репозитория или распаковка проекта выполняется в отдельную папку.

Создание виртуального окружения:

python -m venv .venv

Активация окружения:

.\.venv\Scripts\Activate.ps1

Установка зависимостей:

python -m pip install -r requirements.txt

Запуск приложения:

python -m desktop.main
