## О проекте

**MLDesktopApp** — приложение с графическим интерфейсом на PySide6, которое определяет, является ли банкнота подлинной или поддельной.

Пользователь вводит четыре числовых признака банкноты, выбирает одну из двух обученных моделей и запускает предсказание. Результат отображается в интерфейсе вместе с вероятностями классов, оценкой уверенности и временем выполнения.

### Основные возможности

- Выбор модели: Logistic Regression или Random Forest.
- Ввод четырёх признаков банкноты.
- Классификация и отображение результата.
- Визуализация вероятностей для обоих классов.
- Отображение уверенности модели и времени предсказания.
- История выполненных предсказаний.
- Очистка полей и обработка некорректного ввода.
- Выполнение предсказаний в отдельном потоке, без блокировки интерфейса.

## Используемые модели

В приложении доступны две предварительно обученные модели из библиотеки scikit-learn.

### Logistic Regression

Модель реализована как конвейер (`Pipeline`), включающий стандартизацию признаков и логистическую регрессию:

- `StandardScaler`;
- `LogisticRegression(C=10, max_iter=1000, random_state=42)`.

### Random Forest

Ансамбль деревьев решений со следующими параметрами:

- `n_estimators=100`;
- `random_state=42`;
- `criterion="gini"`.

Обе модели сохранены в каталоге `models/` и загружаются из файлов формата Joblib. Для получения вероятностей классов используется метод `predict_proba()`.

## Фоновое выполнение: QThread и Signal/Slot

Чтобы длительные вычисления не блокировали графический интерфейс, предсказание выполняется в отдельном потоке.

Класс `PredictWorker` наследуется от `QThread`. Он создаёт сервис предсказаний, запускает классификацию и передаёт результат в главное окно через пользовательские сигналы:

- `result_ready` — передаёт словарь с результатом классификации;
- `error_occurred` — передаёт сообщение об ошибке.

Главное окно соединяет эти сигналы со слотами, которые обновляют интерфейс. На время вычисления кнопка запуска блокируется, а после завершения снова становится доступной.

Отзывчивость интерфейса проверялась с временной задержкой в две секунды внутри фонового потока: во время ожидания окно продолжало реагировать на действия пользователя. После проверки задержка была удалена.

## Установка и запуск

Требуется Python 3.12 или совместимая версия Python.

### 1. Клонирование репозитория

```powershell
git clone https://github.com/mlakusss/MLDesktopApp.git
cd MLDesktopApp
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 4. Запуск приложения

```powershell
python -m desktop.main
```
